# my-profile

หน้าเว็บแนะนำตัวสำหรับฝึก Git
คาบถัดไปจะใช้โปรเจคนี้ต่อในเรื่อง HTML และ CSS

## เปิดดูหน้าเว็บ

ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์เพื่อเข้าสู่หน้าเว็บแนะนำตัวของคุณ และสามารถแก้ไขได้ตามต้องการ

## ไฟล์ในโปรเจค

- `index.html` เนื้อหาของหน้าเว็บ
- `style.css` การตกแต่ง
- `.gitignore` รายชื่อไฟล์ที่ไม่ต้องให้ Git เก็บ
